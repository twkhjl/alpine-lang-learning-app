# 檔案與模組索引

## 這份文件的用途

前面的文件偏架構層，這一份偏實務層。  
如果你拿到一個需求，不知道應該改哪個檔，先看這份最省時間。

## 根目錄入口檔

### `index.html`

用途：

- 前台唯一入口頁

你會在這裡看到：

- CDN script 載入
- 前台 CSS 與 JS 掛載順序
- Alpine `x-data="lexiconApp()"` 與 `x-init="init()"`

通常什麼情況會改它：

- 調整前台全域 HTML 骨架
- 調整前台 script / stylesheet 載入順序
- 調整 meta、字型、外部依賴

### `admin-login.html`

用途：

- 後台登入入口

通常什麼情況會改它：

- 調整登入頁版型
- 新增登入頁 DOM hook
- 補狀態區、表單欄位、語系文案掛點

### `admin-dashboard.html`

用途：

- 後台 dashboard 頁面骨架

### `admin-words.html`

用途：

- 後台字詞列表頁骨架

### `admin-word-edit.html`

用途：

- 後台字詞建立 / 編輯頁骨架

### `admin-assets.html`

用途：

- 後台資產引用檢視頁骨架

### `admin-tags.html`

用途：

- 後台標籤管理頁骨架

## 前台主要 JS 模組

### `public/assets/js/supabase-config.js`

用途：

- 放 Supabase URL
- 放 publishable key
- 放 admin login API URL

重要性：

- 非常高

因為這是前後台所有遠端連線的設定入口。

當你遇到這些問題時先看它：

- 前台抓不到資料
- 後台連不到 Worker
- 本地 / 正式環境 URL 不一致

### `public/assets/js/supabase-data.js`

用途：

- 建立前台資料讀取 client
- 載入前台 dataset
- 正規化語言、字詞、標籤、UI 翻譯

常見修改情境：

- 前台資料 shape 改變
- 新增前台 read model 欄位
- 新增語言資料處理

### `public/assets/js/main.js`

用途：

- 前台主應用

已知重要函式位置：

- `function lexiconApp()`：約第 `325` 行
- `async init()`：約第 `513` 行
- `persistPreferences()`：約第 `609` 行
- `applyDocumentLanguage()`：約第 `665` 行
- `openFilterPanel()`：約第 `792` 行
- `toggleWordStatus()`：約第 `947` 行
- `playAudio()`：約第 `1054` 行
- `cardHeadlineText()`：約第 `1198` 行
- `t(key, replacements = {})`：約第 `1243` 行

通常什麼情況會改它：

- 前台互動流程
- 卡片切換規則
- 搜尋 / 篩選邏輯
- 收藏狀態
- 語系切換
- UI 翻譯 fallback

這個檔案風險最高，因為責任最多。

## 快速對照：需求應該找哪裡

### 改前台卡片文案或互動

- `index.html`
- `public/assets/js/main.js`
- `public/assets/css/main.css`

### 改後台側欄

- `public/assets/js/admin-shell.js`
- `public/assets/css/admin.css`

### 改後台登入

- `admin-login.html`
- `public/assets/js/admin-login.js`
- `public/assets/js/admin-auth.js`
- `workers/admin-auth-worker.js`

### 改標籤 CRUD

- `admin-tags.html`
- `public/assets/js/admin-tags.js`
- `public/assets/js/admin-api.js`
- `workers/admin-auth-worker.js`
- `supabase/migrations/*admin_backoffice_write_support*.sql`

### 改字詞儲存結構

- Supabase migration
- `admin-api.js`
- Worker RPC payload
- `main.js` 或 `supabase-data.js`

不要只改其中一層。
